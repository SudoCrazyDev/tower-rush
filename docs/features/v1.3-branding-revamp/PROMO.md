# v1.3 Branding Revamp: promo kit

Render with `npm run promo:rb` in `roadmap-video/` (set `REMOTION_BROWSER` to the installed
Chrome). Source: `roadmap-video/src/promo/Rebrand.tsx`. Output goes to [`promo/`](promo).

## Taglines

- **Tower Rush is now Crown & Keep.**
- Same game, same heroes, same progress. A new name to rule them all.
- Hold the keep. Defend the crown.

## Graphics

| File | Size | Use |
|---|---|---|
| `rb-keyart.png` | 1920×1080 | Announcement post on X, Facebook, Discord, YouTube community |
| `rb-square.png` | 1080×1080 | Instagram and Facebook feed (old logo struck out → new logo) |
| `rb-story.png` | 1080×1920 | Instagram and Facebook stories, TikTok cover |
| `rb-banner.png` | 1500×500 | X and Facebook header |
| `rb-icon.png` | 1024×1024 | Profile picture |
| `rb-reveal.mp4` | 1080×1920, 9 s | Reels, TikTok, Shorts |

Also in `assets/brand/`: `og_image.png` (link previews), `feature_graphic_1024x500.png` (Google
Play) and `key_art_1920x1080.png`.
