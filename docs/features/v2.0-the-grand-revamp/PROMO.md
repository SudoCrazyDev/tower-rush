# v2.0 The Grand Revamp: promo kit

Render with `npm run promo:gr` in `roadmap-video/` (set `REMOTION_BROWSER` to the installed
Chrome). Source: `roadmap-video/src/promo/GrandRevamp.tsx`. Output goes to [`promo/`](promo).

**Framing note:** players don't edit kits; the admin kit editor is a design tool. The promo
says units now *combine* abilities, not that players build them. It also doesn't announce a
specific unit change, because v2.0 rebalances nothing.

## Taglines

- **Every unit, a whole new arsenal.**
- **More abilities per unit. One set of rules for every battle.**
- **The biggest update yet: The Grand Revamp.**
