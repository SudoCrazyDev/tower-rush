# Version reels (WAN 3.0)

Each reel below covers one release, from 1.0 to 2.8. There are 24 reels in all: a hype reel and a meme reel for most versions, and one reel each for 2.5 and 2.6.

## How to generate

1. In the Higgsfield web app, choose **WAN 3.0, image-to-video, 9:16, 720p or higher, about 4-5 s, sound off**.
2. Upload the start image from `docs/marketing/version-reels/starts/<id>.png`. These are already 9:16 and flattened onto a background.
3. Generate three clips per reel:
   - **Beat 1** and **Beat 2**: start image = the start image, prompt = the beat text + the style line.
   - **Beat 3 (loop)**: start image AND end image = the start image, prompt = the loop line. If WAN 3.0 has no end-frame input, skip beat 3; the reel becomes 8-10 s.
4. Paste the three clip links in chat with the reel id (for example `v1.1-hype`). Claude then joins them, burns in the hook and CTA, uploads to R2 and adds the reel to admin #/marketing.

**Style line**, which goes at the end of every beat prompt:

> Flat 2D cartoon game art, thick dark navy outlines, two-tone cel shading, chunky chibi proportions, bright saturated colors, keep the characters' designs identical to the start image, top 20% of the frame calm for text, no text, no watermark.

**Loop line** (for beat 3):

> The scene settles back into this exact frame, the characters hold a confident pose with gentle idle motion and drifting sparkles, camera slowly drifts.

Generate 2-3 takes of each beat and keep the best one.
